## 为什么做这些

我不满足于"会用工具"。三个项目对应投研的三个真实痛点：

1. **信息来得不够快、不够连续** → 自己写调度，让数据每天准时到邮箱（`personal-agent`）。
2. **年报太长，找一句话要翻 200 页** → 自己建索引，让答案带出处（`annual-report-qa`）。
3. **通用大模型不懂某公司的话术口径** → 自己造语料、自己微调，并做四格对照验证（`junzheng-finance-qa`）。

第三个项目里我特意做了「训练过 / 没训练过 × 原问法 / 换问法」的对照——**我不太相信"跑通了"就等于"学会了"，所以每个项目都会留一份评测记录，包括失败的那些**。
