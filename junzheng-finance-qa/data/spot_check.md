# 问答数据人工抽检记录

## 抽检对象

- 原始数据：`data/qa_dataset_raw.jsonl`，由 DeepSeek（deepseek-chat）按 `generate_qa.py` 从
  君正股份 7 份财报原文批量生成，共 540 条。
- 覆盖报告：2023/2024/2025 年报、2023/2024/2025/2026 半年报。

## 抽检方法

分两类自动判定 + 人工复核：

1. **数字级回源**：把每条 `key_facts` 里的数字逐个去掉千分位逗号，回出处页码全文做子串匹配，
   任一数字找不到即判「疑似编造/错页码」。
2. **定性事实回源**：对无数字的事实，用「双字词重叠度≥50%」判断（能容忍改写、能识别凭空编造）。
3. **空洞避答检测**：答案若只有“以公告为准/未披露/请查阅公告”等套话且无实质数字，判为无效。

脚本：`spot_check.py`。逐条明细见 `spot_check.csv`。

## 抽检结果

| 项目 | 数量 |
| --- | --- |
| 原始生成 | 540 |
| 通过（进入训练集） | 485 |
| 删除 | 55 |
| 　其中：事实未回源/错页码 | 44 |
| 　其中：空洞避答 | 11 |

## 删除原因分析

- **空洞避答（11 条）**：模型在部分片段上直接“拒答”（如“具体数据以公告为准”“原文片段未包含该数据”），
  没有给出可训练的有效内容，全部删除。
- **事实未回源/错页码（44 条）**：主要是跨年度对比数据被引到了错误的页码（数字本身真实、但出处标错），
  以及少量会计政策细节的表述与原文对不上。为保持“答案出处可追溯”，一律删除。

## 结论

真实大模型批量生成时，“避答套话”和“出处标错页”是两类典型噪声，`spot_check.py` 已自动拦截。
本轮 540 → 485（保留率约 90%）。剩余数据仍建议人工抽查若干条确认语气合规；数字层面的硬性错误
已基本被事实回源覆盖。
