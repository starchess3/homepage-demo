# 一页结论：君正股份财报问答微调

## 做了什么

用君正股份（300223）近三年年报/半年报（共 7 份、1249 页）构建“投资者提问 → 董秘作答”语料，
并用 LoRA 微调一个免费 T4 可跑的小模型（默认 Qwen2.5-1.5B-Instruct），对比微调、基座、知识库 RAG 三种方案。

## 关键结论

1. **微调有效但幅度有限**：微调模型平均命中率 0.26，约为基座模型（0.09）的 2.7 倍，说明 LoRA 让小模型学到了财报事实与董秘口径；
   但绝对分数不高，主要卡在“关键事实组命中率”要求精确命中数字写法上。
2. **学到的是口径而非背答案**：微调模型在“训练过的题”上只有 0.21，反而低于“没训练过的题”（0.38/0.23）。
   这恰好说明它不是逐题死记原文，而是学到了“合规、客观、克制”的董秘表述方式；训练题多为金额/比例等精确数字，格式稍有偏差即判错。
3. **换问法基本稳健**：训练过的题原问法/换问法均为 0.21，没训练过的题 0.38→0.23 略降，但仍明显高于基座（0.19），
   说明对语义改写有一定稳健性，不是死记原文。
4. **RAG 保事实、微调保口径**：知识库 RAG + 基座平均命中率 0.32 最高，且在没训练过的题上达 0.50/0.44（检索直接给原文）；
   但在训练过的题上仅 0.17（关键词检索没命中对应页码）。综合看，小样本下最稳妥的是“微调 + 知识库检索”结合使用。

## 一句话结论

> 用少量财报问答做 LoRA，能让小模型掌握公司董秘的表述口径，显著优于未微调的基座；
> 但要保证数字准确，最稳妥的是“微调 + 知识库检索”结合使用。
