# 对照表：微调 vs 基座 vs 知识库RAG

## 评测口径

- 任务：给定投资者问题，由模型以“董秘”身份作答，答案只依据君正股份财报。
- 题集：8 题，其中 4 题来自训练集（训练过的题），4 题为未训练过的新题（没训练过的题）；
  每题各准备原问法、换问法两版，共 16 条（见 `eval/eval_questions.jsonl`）。
- 打分：每条答案按“关键事实组命中率”计分（0~1）。每题 `gold` 里列出若干事实组，
  只要命中该组任一写法即算对；单题得分 = 命中事实组数 / 总事实组数。
- 三种方案：
  - **微调模型**：Qwen2.5-1.5B-Instruct + LoRA（`train_lora.ipynb` 产出）。
  - **基座模型**：同一 Qwen2.5-1.5B-Instruct，未微调。
  - **知识库RAG + 基座模型**：把财报原文按页建库，按关键词检索 top-3 页拼进提示词，再交给未微调的基座模型作答。

> 注：下面为 Colab 实际跑出的关键事实命中率（0~1，保留两位小数）。

## 表 1 四格对照（微调模型）

|          | 原问法 | 换问法 |
| -------- | ------ | ------ |
| 训练过的题 | 0.21   | 0.21   |
| 没训练过的题 | 0.38   | 0.23   |

读法：左列看“记住原题 vs 迁移到新题”，左右两列看“对同一语义换问法的稳健性”。

## 表 2 对照组（基座模型，未微调）

|          | 原问法 | 换问法 |
| -------- | ------ | ------ |
| 训练过的题 | 0.00   | 0.00   |
| 没训练过的题 | 0.19   | 0.19   |

## 表 3 对照组（知识库RAG + 同一个基座模型）

|          | 原问法 | 换问法 |
| -------- | ------ | ------ |
| 训练过的题 | 0.17   | 0.17   |
| 没训练过的题 | 0.50   | 0.44   |

## 表 4 三方案总览（平均命中率）

| 方案 | 平均命中率 |
| ---- | ---------- |
| 微调模型 (LoRA) | 0.26 |
| 基座模型 (未微调) | 0.09 |
| 知识库RAG + 基座模型 | 0.32 |

## 实际结果解读

- **微调有效但幅度有限**：微调平均命中率 0.26，约为基座模型（0.09）的 2.7 倍，说明 LoRA 确实学到了财报事实与董秘口径；
  但绝对分数不高，主因是“关键事实组命中率”要求精确命中数字写法，模型对金额单位（亿/万元）、逗号、百分比的表述容易产生轻微偏差。
- **微调并非“背答案”**：微调模型在“训练过的题”上只有 0.21，反而低于“没训练过的题”（0.38/0.23）。说明小数据 LoRA 更多学到的是
  “董秘作答格式/口径”，而不是逐题死记原文；训练题多为精确财务数字，打分更严。
- **换问法基本稳健**：微调模型训练过的题换问法不降（0.21→0.21），没训练过的题略降（0.38→0.23），整体说明学到的是语义而非原文。
- **RAG 保事实**：知识库 RAG + 基座平均最高（0.32），在“没训练过的题”上最强（0.50/0.44），因为检索直接给了原文；
  但在“训练过的题”上偏低（0.17），说明该组题的关键词检索没命中对应页码。
- **结论落点**：小数据 LoRA 学的是“口径/格式”，RAG 保的是“事实召回”，二者互补，组合使用最稳。
